# UOMW

Unity Application to Load Morrowind Maps

Mostly based off of works by

[Merged Lands](https://github.com/DavidVonDerau/merged_lands)

[OpenMW](https://github.com/OpenMW/openmw)

[TesAnnWyn](https://github.com/theomission/TESAnnwyn)

[NifLib.NET](https://github.com/dol-leodagan/niflib.net)

[ESMSharp](https://github.com/demonixis/ESMSharp)

Currently Full Map Load, Cell Statics, added autogenerated Normal maps
